# Contributing

Use Node.js 22.12 or newer. Run `npm ci`, `npm test`, and `npm run build` before submitting changes.

Keep gameplay clocked to audible output, charts playable with at most two fingers, and imported audio private. Verify touch changes on a portrait viewport and a real Android device when available. Honor reduced-motion settings and keep decorative effects bounded.

Only submit audio/artwork you own or can redistribute. Include the exact source, license, attribution, and any modifications. Do not commit device data, imported songs, credentials, generated APKs, or local test evidence. Generated local evidence belongs in the ignored `output/` directory.
